[[spec-workstream-atlas.atlas-model.current-system-form|Current System Form]] is the living conceptual representation of what a system is now.

It is not the source code and it is not the historical plan set. It is the named form Atlas maintains so a person or agent can understand the system through product, model, operation, experience, capability, invariant, and evidence language before diving into implementation details.

For BookOps, the current system form includes items such as [[bookops.model.book|Book]], [[bookops.reader-experience|Reader Experience]], sharing, conversations, translations, and source authoring.

For Ontahi, the current system form includes items such as [[ontahi.model.entity|Entity]], [[ontahi.model.domain-operation|Domain Operation]], [[ontahi.model.durable-operation|Durable Operation]], authority, refs, operation contracts, and runtime boundaries.

The current form changes when work lands, when old plans are reconciled, when a concept is promoted, split, merged, or retired, or when evidence shows the model is stale.
