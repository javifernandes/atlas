Atlas Model defines the language the atlas uses to describe systems: atlas items, item types, system form, work items, transformations, evidence, relations, states, and practices.

It is not a complete metamodel yet. It is the smallest shared vocabulary needed to recover product control from scattered plans, implementation work, and historical decisions.
