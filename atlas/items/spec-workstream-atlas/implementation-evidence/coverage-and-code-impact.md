Coverage And Code Impact connects a workstream to changed files, package boundaries, PR diffs, Codecov-style coverage deltas, and review risk.

For an item in review, the atlas should eventually show whether the implementation has tests near the affected code and where the uncovered or high-risk surface still lives.
