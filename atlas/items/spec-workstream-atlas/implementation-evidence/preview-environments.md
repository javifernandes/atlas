Preview Environments connect atlas items to staging, preview, or ephemeral deployments where the feature can be tried in something closer to the real product.

This is harder than static evidence because it depends on branch deployments, seeded data, access control, and stable entry URLs. It may start as manual links and later become Vercel/GitHub driven.
