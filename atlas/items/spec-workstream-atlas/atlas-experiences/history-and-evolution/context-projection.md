Context Projection is the orientation view around a selected atlas item.

It answers a different question from local evolution: where does this item fit in the larger system?

It can show:

1. parent and ancestor items,
2. dependencies and support links,
3. supported-by links,
4. lateral related items,
5. sibling branches,
6. nearby model concepts,
7. implementation or evidence surfaces that help orient the reader.

Context should be accessible from the selected item without overwhelming the Evolution board. The same relation can be true in the atlas graph and still be inappropriate for a local work-planning lens.
